In coherent mode RM maps the GR subcontext header through the GH100 static coherent-FB kernel mapping, which cannot map discontiguous surfaces — hence memdescGetContiguity(pMemDesc, AT_CPU) failing and NV_ERR_INSUFFICIENT_RESOURCES surfacing as CUDA's "out of memory". With EnableNUMA: 0 that path is forced and no regkey relaxes it. acos cannot pass in this mode, by design of the limitation, not because of anything in your tray.

The subctx header allocated (discontiguous, as it apparently always is) → coherent mode routes its CPU map through the static path → memdescGetContiguity(pMemDesc, AT_CPU) false → NV_ERR_NOT_SUPPORTED → remapped upward to NV_ERR_INSUFFICIENT_RESOURCES → CUDA reports out-of-memory.
